# EASEBILL — Smart Automated Billing

> A modern billing application concept focused on faster product capture, cart management, payment workflows and administration.

[![Next.js](https://img.shields.io/badge/Next.js-16-black)](#)
[![React](https://img.shields.io/badge/React-19-61DAFB)](#)
[![TypeScript](https://img.shields.io/badge/TypeScript-5-3178C6)](#)
[![UI](https://img.shields.io/badge/UI-Tailwind%20%2B%20Radix-38B2AC)](#)

## Core workflow

**Camera / Product Capture → Product Selection → Cart → Billing → Payment → Success / Transaction**

## Included components

- Camera scanner
- Shopping cart
- Product/admin controls
- Payment section
- Payment-success state
- Region selector
- Demo mode
- Reusable UI
- Admin area and API routes

## Stack

Next.js 16 • React 19 • TypeScript • Tailwind CSS • Radix UI • React Hook Form • Zod • Recharts • Lucide React

## Run locally

    npm install
    npm run dev

Production:

    npm run build
    npm start

Lint:

    npm run lint

## Security

Do not commit .env files, payment secrets, API credentials or service-account keys. Real payment integrations should use trusted server-side provider flows.
